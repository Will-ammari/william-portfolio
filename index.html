Holol Academy

Academic operations & learning platform

🔒 Private source

Bilingual Laravel platform spanning the public site, admissions, academic administration, learning delivery, assignments, student submissions, evaluations, and academic records.

Engineering challenge

The backend needed to preserve academic scope and historical integrity across several roles while handling private files, deadline-driven workflows, resubmissions, and reliable notifications.

Backend work
  • Permission + Program/Cohort scope enforcement across Super Admin, Sub Admin, and Student workflows.
  • Versioned submission cycles and append-only evaluation release protected by database transactions and row locks.
  • Queue- and scheduler-driven deadline, missing-document, late, Retake, and result notifications with idempotent delivery recovery.
  • Private file streaming, controlled academic records, exports, integrity checks, pagination, and query-level performance hardening.

Arsltek

OTP, WhatsApp messaging & client billing platform

🔒 Private source

Laravel backend that exposes client APIs and a client portal for OTP delivery, WhatsApp Cloud, bulk template messaging, package usage, provisioning, payments, and delivery status tracking.

Engineering challenge

Messaging and billing state had to stay consistent while multiple clients, gateways, webhooks, quotas, payment callbacks, and asynchronous delivery processes were operating at the same time.

ProcurePilot AI

Multi-tenant procurement SaaS backend

GitHub ↗

API-first Laravel backend for purchase requests, supplier quotes, AI-assisted quote analysis, approvals, invoices, VAT, scorecards, audit logs, and attachments.

Engineering challenge

The system needed tenant-safe procurement workflows, consistent approval and purchasing state, reliable background processing, and a clean boundary between Laravel business logic and the AI analysis service.

Backend work
  • Multi-tenant scoping, policies, Sanctum authentication, service-layer business logic, and auditable procurement state transitions.
  • Database transactions and concurrency controls around critical workflow operations, plus queues and background jobs for asynchronous work.
  • FastAPI integration for AI-assisted analysis behind a Laravel-owned domain model rather than placing core business rules in the AI service.
  • Dockerized local environment, Redis, CI, PHPStan/Larastan, OpenAPI/Postman documentation, health monitoring, and a broad automated test suite.
